# Instructions

- This project is a wrapper to automatically donload the latest Linux version of the game and install it as an AppImage with an icon and a user friendly display name
- Goal is to have the game smoothly installed on Omarchy Arch Linux
- The game releases new version frequently and it's important that it's easy to install the game but keep the local game data intact
- Logo for the game can be found here: https://github.com/actualraptor/extinction-protocol/blob/main/native/assets/branding/extinction-protocol-logo.png
- Use GitHub releases as source of truth
- Use this repository as source: https://github.com/actualraptor/extinction-protocol/releases/latest
- The link above is both the repo + the latest release
- The release name we're interested in has these patterns included (try kebabcase and camelcase): "extinction-protocol", "Linux", ".tar.gz"
- Historical exact file-name is: Extinction-Protocol-Linux-0.14.1-UNVERIFIED.tar.gz where 0.14.1 is the version.
